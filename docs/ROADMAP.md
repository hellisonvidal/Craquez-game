# Roadmap

## v0.1 (esta versão)
- [x] Campo 11×11, Futsal 5×5, Street 3×3 com tabela
- [x] Física da bola 2.5D, movimento com inércia, stamina
- [x] Passe, enfiada, passe alto, chute com força, de primeira, cabeceio
- [x] Dividida, carrinho, faltas simples, lateral, escanteio, tiro de meta
- [x] Goleiro com posicionamento, mergulho, defesa/espalmada e reposição
- [x] PvP local (2 controles / teclado dividido) e contra CPU (3 níveis)
- [x] Xbox / PlayStation / teclado / toque, vibração
- [x] Presets de qualidade + detecção automática
- [x] Rostos vetoriais procedurais (48)
- [x] Testes headless + CI com builds Windows/Android
